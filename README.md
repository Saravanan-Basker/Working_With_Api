# Working_With_Api

🦸‍♂️ Cartoon Character API Project

This project is a simple Cartoon Character REST API built using Python. It reads cartoon character data from a CSV file and allows users to search, retrieve, and analyze the data in structured formats.

📌 Project Features

Extracts cartoon character data from a CSV file (list_dict_data.csv)
Cleans and processes nested list/dictionary-like string data
Converts the data into structured formats (lists and dictionaries)
Serves the data as a basic API interface via the Jupyter Notebook
Supports exploration, filtering, and pretty printing of JSON data


📁 Files in this Repository

File	Description
Cartoon_Api.ipynb	Main Jupyter Notebook that processes and exposes the cartoon character data
list_dict_data.csv	CSV dataset containing character names, shows, and attributes (in list/dict string format)
README.md	Project overview and usage instructions

🛠️ Technologies Used

Python 3
Jupyter Notebook
Pandas
ast (Abstract Syntax Trees) module for safe evaluation of string-encoded Python literals
JSON formatting
